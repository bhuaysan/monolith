# MONOLITH

A high-fidelity first-person exploration vertical slice built with Godot.

## Concept

MONOLITH is set inside a monumental corporate residential/office megastructure approximately 800–1200 meters tall. Its architecture should make the player feel physically insignificant. The visual direction is futuristic but deliberately avoids conventional cyberpunk clichés.

## Project Objective

Explore how far one developer can push a highly polished 3D game prototype using AI-assisted development.

## Development Model

Human Project Owner
→ ChatGPT Orchestrator
→ Codex / Claude Code implementation
→ Git repository
→ review / iteration

## Current Status

Pre-production / project bootstrap.
