# WORLD SCALE

**Status:** DRAFT

## Initial Scale References

| Element | Approximate Scale |
|---|---:|
| Human | ~1.75 m |
| Door | 2.4–3 m |
| Standard floor | ~4.5 m |
| Corporate floor | ~6 m |
| Atrium | 40–100 m |
| Tower | 800–1200 m |
| Skybridge | potentially hundreds of meters |

## Scale Principle

Scale requires contrast between human-scale objects and megastructure-scale forms. If every object is enormous, nothing feels enormous. The visual hierarchy should move from human, to door, to room, to atrium, to building, to megastructure.
