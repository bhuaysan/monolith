# ROADMAP

**Status:** DRAFT

## M0 — Foundation

Repository, governance, project configuration, and workflow.

## M1 — Greybox

Validate scale and spatial composition in a small architectural greybox.

## M2 — Exploration Systems

Implement only the interaction systems required by the vertical slice.

## M3 — Lighting Prototype

Develop a representative visual benchmark scene and rendering direction.

## M4 — Architecture Kit

Build the modular architecture kit required for selected playable areas.

## M5 — Hero Scene

Bring one representative location to near-final visual quality.

## M6 — Megacity Illusion

Use distant architecture and atmosphere to imply a much larger world.

## M7 — Complete Vertical Slice

Connect the selected playable areas into a complete exploration experience.

## M8 — Polish

Focus on performance, sound, transitions, animation, interaction feel, lighting, and final presentation.
